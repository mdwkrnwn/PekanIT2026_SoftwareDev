# 📖 Tentang Bakool

**Bakool** merupakan platform digital berbasis **Location-Based Service (LBS)** yang membantu masyarakat menemukan UMKM lokal berdasarkan lokasi, kategori, maupun kebutuhan mereka.

Melalui integrasi **GeoMaps**, pengguna dapat menjelajahi UMKM di sekitar, melihat detail toko, membaca ulasan, menyimpan UMKM favorit, hingga memperoleh informasi usaha secara lengkap.

Selain membantu pengguna, Bakool juga menyediakan **Dashboard Pemilik UMKM** yang memungkinkan pelaku usaha mengelola produk, membuat promo, melihat statistik toko, serta memperoleh rekomendasi bisnis melalui **Bakool AI Business Assistant** berbasis **Google Gemini AI**.

Bakool juga menghadirkan **Bakool AI Assistant** yang membantu pengguna menemukan UMKM, memberikan rekomendasi kuliner, menjawab pertanyaan mengenai platform Bakool, serta memberikan edukasi ringan mengenai UMKM.

Bakool dikembangkan sebagai solusi digital untuk mendukung transformasi UMKM Indonesia.

## 👤 Bakool AI Assistant

Tersedia pada Landing Page.

Bakool AI Assistant membantu pengguna untuk:

- 🔍 Menemukan UMKM di sekitar lokasi pengguna.
- 🍜 Memberikan rekomendasi kuliner, cafe, hidden gem, dan produk lokal.
- 📍 Memberikan informasi mengenai UMKM yang tersedia di Bakool.
- ❓ Menjawab pertanyaan mengenai Bakool dan fitur-fiturnya.
- 📚 Memberikan edukasi mengenai UMKM melalui artikel Bakool.
- ⚡ Membantu pengguna menemukan informasi dengan cepat.

---

- 📊 Analisis performa usaha.
- 💡 Pengembangan bisnis UMKM.

# 🚀 Instalasi

Bakool dapat dijalankan menggunakan **Repository GitHub** maupun **source code** yang disertakan pada berkas kompetisi.

## Menggunakan Repository GitHub

Clone repository

```bash
git clone https://github.com/mdwkrnwn/PekanIT2026_SoftwareDev.git
```

Masuk ke folder project

```bash
cd PekanIT2026_SoftwareDev
```

Install dependency

```bash
npm install
```

---

## Menggunakan Source Code

Ekstrak file source code yang telah diunduh, kemudian masuk ke folder project melalui Terminal atau Command Prompt.

```bash
cd PekanIT2026_SoftwareDev
```

Install dependency

```bash
npm install
```

# ⚙️ Environment Variables

Buat file

```text
.env.local
```

Isi dengan konfigurasi berikut

```env
NEXT_PUBLIC_SUPABASE_URL=YOUR_SUPABASE_URL

NEXT_PUBLIC_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY

GOOGLE_GENERATIVE_AI_API_KEY=YOUR_GEMINI_API_KEY
```
